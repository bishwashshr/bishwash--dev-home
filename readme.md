# Bishwash — Personal Portfolio

My personal website, built with React and TypeScript. A home for my work, projects, and interests in backend engineering, data engineering, and fintech applications.

## About me

I focus on backend and data engineering, building applications around fintech.

My broader toolkit includes .NET Core, C#, TypeScript, React, Angular, PostgreSQL, SQL Server, Redis, Kafka, RabbitMQ, and AWS.

## Tech stack

- **React** — user interface
- **TypeScript** — typed application code
- **Vite** — development server and production builds

## Development

Install dependencies and start the development server from this folder:

```sh
npm install
npm run dev
```

Additional commands:

```sh
npm run build    # Type-check and build for production
npm run lint     # Run ESLint
npm run preview  # Preview the production build locally
```

The app entry point is `src/main.tsx`, and the main component is `src/App.tsx`. Production builds are generated in `dist/`.
